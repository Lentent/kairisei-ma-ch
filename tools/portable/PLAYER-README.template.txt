乖离性百万亚瑟王｜玩家必读
============================

你只需要安装同一发布目录里的 client.apk，不需要下载或运行 server ZIP。
客户端内置的默认地址是：{{HOST}}:{{PORT}}（{{MODE}}）。

开始游戏
1. 向服主确认服务器已经启动。
2. 安装 client.apk，并至少打开一次游戏；首次启动会自动创建服务器地址文件。
3. 退出游戏，用文件管理器进入：
   内部存储/Android/data/com.netease.ma.netease/files/
4. 打开 local_server.txt，把第一行改成服主给你的 IPv4:端口，然后保存并重新打开游戏。
5. 首次进入会下载资源，所需时间取决于网络速度，请保持服务器在线。

local_server.txt 的默认内容
- 默认值就是本批 APK 的内置地址：{{HOST}}:{{PORT}}。
- 如果这个地址正是服主给你的地址，无需修改；服务器地址变化时才需要编辑。
- 客户端不再读取 Download 目录中的同名文件，以免玩家改错位置。

安装提示
- 如果系统提示“禁止安装未知应用”，只为当前使用的文件管理器临时允许安装即可。
- 如果提示签名不一致，说明设备上已有其他签名版本。卸载旧版本会删除它的本地应用数据，
  请先确认是否需要保留；不确定时先联系服主。
- 客户端是 32 位应用。Android 16 设备需要支持 32 位应用；纯 64 位设备无法运行。

连接失败
1. 确认你安装的是与本次 server 同批发布的 client.apk。
2. 确认文件位于 Android/data/com.netease.ma.netease/files/local_server.txt，内容只有正确的 IPv4:端口。
3. 确认服主提供的服务器状态为“正在运行”。
4. 局域网服：手机与服务器电脑必须连接同一网络，关闭会隔离设备的访客 Wi-Fi。
5. 公网服：联系服主检查公网 IP、TCP {{PORT}} 和 {{BATTLE_PORT}} 的端口映射。
6. 不要自行修改 APK，也不要把 Admin 地址或密码发给其他人。

服务器地址变化后，只修改 Android/data/com.netease.ma.netease/files/local_server.txt 的第一行，然后重启游戏。
