# 乖离性百万亚瑟王

> **本项目永久免费，请勿付费购买。** 项目主页：[kuuhaku1314/kairisei-ma-ch](https://github.com/kuuhaku1314/kairisei-ma-ch)

在自己的电脑或服务器上运行服务端，用 Android 手机或模拟器重温国服的卡牌、剧情和副本，也可以和朋友连接同一服务端组队。游戏进度保存在自己的服务器上，无需官方账号。

目前仍在测试，部分演出、设备兼容性和多人场景还需要实际游玩确认。

## 下载与解压

需要准备 `client.apk` 和**同一版本的全部服务端 RAR 分卷**。将各卷放在同一个文件夹，完整解压出 `kairisei-ma-cn602-server` 后再启动。Linux 使用支持 RAR5 的解压工具展开同一套分卷。

一套包同时包含 Windows x64、Linux x64、Linux ARM64 的服务端和启动脚本，共用 `resource-set` 游戏资源。保留整个解压目录，不能只复制一个 exe。使用发布包无需安装 Go、Python 或 Unity

## Windows：启动服务

1. 双击解压目录中的 **`Kairisei-Launcher.exe`**。
2. 选择使用场景：同一台电脑上的 Android Emulator 选“Android 模拟器”；手机游玩选“局域网”，地址填写电脑的局域网 IPv4。
3. 点击“启动服务”，等待右上角显示正在运行，再打开游戏。游玩期间保持服务运行。
4. 结束后点击“停止服务”，等待正常停止再关闭电脑或移动存档。

手机和电脑应处于同一局域网。默认游戏端口为 TCP **26020**，战斗端口为 TCP **26021**；Windows 弹出网络访问提示时，允许服务在所用的专用网络中通信。

## Android：安装与连接

安装包内提供的 `client.apk`。首次打开时按提示授予资源存储权限；新账号从新手教程开始，游戏资源由自己的服务端下载。

| 游玩方式 | 游戏连接地址 |
| --- | --- |
| 同一台电脑上的 Android Emulator | 默认 `10.0.2.2:26020` |
| 手机或其他模拟器 | 使用客户端能访问到的服务端 IPv4 和主端口 |

手机连接需要修改游戏自己的地址文件。**安装完成后，先打开游戏进入标题首页**，让游戏自动创建 `Android/data` 下的应用目录，再退出游戏。随后才能将地址文件复制到对应目录；文件通常位于内部存储：

```text
Android/data/com.netease.ma.netease/files/local_server.txt
```

将内容改为启动器中设置的地址，例如下面这一行，再重新打开游戏：

```text
192.168.2.149:26020
```

请换成你自己的服务器地址，只填 `IPv4:端口`。游戏读取应用 `files` 下的文件，放在 `Download` 中无效。更换主端口后也要同步修改这里。

手机上可以使用 **ZArchiver** 解压／文件管理软件，方便地将填好服务器地址的 `local_server.txt` 复制到 `Android/data/com.netease.ma.netease/files/`，覆盖同名文件。按系统提示授予目录访问权限，复制完成后重新打开游戏；若系统不允许访问该目录，可使用下面的 ADB 方法。

<details>
<summary>手机文件管理器无法访问 Android/data 时</summary>

可使用电脑上的 ADB 写入同一文件。开启手机调试并授权电脑后，在电脑上准备好内容正确的 `local_server.txt`，执行：

```sh
adb devices
adb -s 设备序列号 push local_server.txt /sdcard/Android/data/com.netease.ma.netease/files/local_server.txt
```

把“设备序列号”替换成第一条命令显示的目标设备，确认推送成功后重新打开游戏。这一步只修改连接地址。

</details>

首次下载资源到最后时，可能会停在进入游戏的页面不动。遇到这种情况，完全关闭游戏后重新打开即可尝试继续进入；无需卸载或清除已下载资源。

## 三端命令行启动

在完整解压目录中选择对应入口：

| 系统 | 启动入口 |
| --- | --- |
| Windows x64 | `Start-Server.cmd`，默认模拟器配置；手机连接建议使用图形启动器 |
| Linux x64 / x86_64 | `sh Start-Server-linux-amd64.sh 服务器IPv4 26020` |
| Linux ARM64 / aarch64 | `sh Start-Server-linux-arm64.sh 服务器IPv4 26020` |

Linux 将 `服务器IPv4` 替换成手机能访问到的地址；需要 `/bin/sh` 和 coreutils。脚本会设置服务端执行权限，前台运行，按 **Ctrl+C** 或发送 **SIGTERM** 正常停止；末尾加 `--dry-run` 可以只检查启动参数。ARM64 版本已构建，尚待 ARM64 主机实测。

Windows 命令行启动后，用 `Stop-Server.cmd` 停止。不同平台的程序共用资源，但不要同时用多个服务端进程打开同一份存档。

## 存档、后台与更新

- **存档**：服务端目录下的 `_local/data/`，首次启动时创建。备份前正常停止服务，再复制整个目录。
- **后台**：Windows 点击“打开 Admin”，默认地址为 `http://127.0.0.1:26022/`，仅允许在服务端本机访问。可配置卡池、活动与副本，或给账号发放礼物。
- **日志**：Windows 点击“查看日志”；服务端运行记录位于 `_local/runtime/`，Linux 也会在启动终端显示日志。
- **更新**：先查看该版存档兼容说明，将新包解压到新目录，正常停服后再迁移可兼容的存档。APK 相同时无需重装；需要更新时优先覆盖安装，保留原应用数据。

卸载游戏或清除应用数据会移除本机登录信息和已下载资源，请勿把它当作常规更新步骤。服务端存档和手机应用数据是两处独立的数据。

## 遇到问题

- **解压失败**：确认所有分卷都已下载完整、来自同一版本，并放在同一目录，从 `part1.rar` 开始解压。
- **连接失败**：先确认启动器显示服务已运行，再核对手机地址文件、同一局域网及游戏／战斗两个端口。浏览器能打开主页，只能说明 HTTP 端口可达。
- **更新后进度不见了**：先检查是否启动了新目录中的空存档，保留旧目录备份后再核对，避免反复清除数据。
- **卡住、黑屏或功能异常**：请在 [Issues](https://github.com/kuuhaku1314/kairisei-ma-ch/issues) 中附上版本、设备型号与系统、复现步骤和截图；有服务端报错时附相关日志片段。
