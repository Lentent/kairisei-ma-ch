# 乖离进化素材消耗

乖离进化（`evolution_type = 1`）保留背包和仓库中选中的素材卡，按配方逐张扣除素材名声，并重算名声相关属性。素材卡的唯一 ID、等级、经验和忠诚度保留。

扣除后每张素材卡必须至少保留 1 点名声。例如配方需要扣 3 点名声，素材卡须有至少 4 点；有 8 点则扣到 5 点。名声不足时返回提示，不扣素材名声或金币。此条件也避免原生客户端在素材名声耗尽时移除卡牌。

素材卡数量仍须匹配配方，不能合并多张卡的名声，也不能用堆叠素材替代卡牌名声。锁定或处于使用中的素材卡沿用原有可用性限制。

普通、骑士和限界进化的素材消耗规则保留。更新服务端程序并重启后生效，无需修改配方资源或迁移存档；此前已消耗的卡牌不会自动恢复。
