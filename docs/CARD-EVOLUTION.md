# 乖离进化素材消耗

乖离进化（`evolution_type = 1`）按配方逐张消耗背包和仓库中选中的素材名声。

素材卡名声等于所需名声时允许进化，本次进化消耗整张素材卡。名声大于需求时，扣除所需名声后保留素材卡，并重算名声相关属性；唯一 ID、等级、经验和忠诚度保留。例如配方需要 3 点名声，有 3 点则消耗卡牌，有 8 点则扣到 5 点并保留卡牌。同一次进化可以同时消耗名声刚好够的卡牌、保留仍有剩余名声的卡牌；未选中的卡牌不受影响。

任意素材卡名声少于需求时返回提示，整次进化不消耗卡牌、素材名声或金币。金币不足、进化目标不可用等校验失败时也不消耗。

素材卡数量仍须匹配配方，不能合并多张卡的名声，也不能用堆叠素材替代卡牌名声。锁定或处于使用中的素材卡沿用原有可用性限制。

普通、骑士和限界进化的素材消耗规则保留。更新服务端程序并重启后生效，无需修改配方资源或迁移存档；此前已消耗的卡牌不会自动恢复。
