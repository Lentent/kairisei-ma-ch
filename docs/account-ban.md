# 后台封禁与解封

后台 → 玩家账号 → 搜索玩家 UID →「封禁 / 解封」。

未封禁账号：填写必填原因（1–500 字）、小时数（0 表示永久），核对玩家和期限后确认。
已封禁账号：显示原因及到期时间，确认后解封。限时封禁到期自动允许重新登录。

封禁按角色 UID 生效，不依赖 IP。保留存档和账号绑定；封禁立即废止旧登录会话，解封或到期也不会恢复旧会话，玩家需要重新登录。游客 UUID 登录、账号密码登录、游戏 HTTP 请求、联机建房/入房/重连及已连接玩家的后续消息均检查访问状态。已建立的联机连接在下一条消息（包括心跳）时被拒绝并断开，不保证点击封禁的同一瞬间断开所有网络连接。

操作日志可筛选「封禁账号」「解封账号」。记录原因、期限和 UID；操作与会话撤销在同一数据库事务提交。新增 cn_account_ban 表，启动时自动创建，不需手工改库。部署需更新并重启服务端；本地 Git 提交/推送不会自动更新线上服务器。

接口（沿用后台认证及 X-Kairisei-Admin-Action: apply 写操作校验）：
- GET /api/accounts/{userID}/ban：读取状态。
- POST 同地址：封禁 {"banned":true,"reason":"原因","until_unix":0}；解封 {"banned":false}。until_unix 为 Unix 秒，0 表示永久。

封号只约束对应 UID，不阻止同一人新注册其他角色。
