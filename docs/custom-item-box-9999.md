# 黑暗切尔莉吞噬者礼盒（9999）

复用 8887 的 GACHA / GACHA_EXEC 机制和图标 10120，独立功能值 69999999。
每个箱子随机发放一项、数量 1；素材 20000014、20000019、20000024、20000029、20000004 各 18.8%，妮妙皮肤 16 为 3%，称号 26093002（超弩级黑暗切尔莉吞噬者挑战者）为 3%。整数权重为五个 188 和两个 30，总和 1000。

## 源码

道具开箱专用校验支持类型 14（皮肤）和 18（称号），数量必须为 1。加载 master 和创建账号运行状态都使用该校验，收藏 ID 仍需由实际奖励目录验证。普通付费扭蛋的校验规则不变。已有发奖逻辑负责扣箱和登记收藏；重复收藏不发额外补偿。相关测试覆盖合法性、权重、扣箱、重复领取、未知收藏及空库存。

## 配套资源

`server/config/custom-item-box-9999.json` 是可版本管理的资源构建输入，不是自动加载的启动配置。当前已制作好的运行包仍位于 `E:/123/kairisei`；此次仅合并源码，不把旧版资源或服务端二进制覆盖到本仓库。

制作或更新配套 resource-set 时：

1. 将输入的 `item` 按 item_id 合并进 `cn602-item-runtime-master.json` 的 items，将 `item_gacha_profile` 按 item_id 合并进 item_gacha_profiles，禁止重复 ID/功能值。
2. 需要称号 26093002 时，将 required_honor 合并进称号 master 的定义列表，并确认客户端 honor.csv 有该称号；妮妙 16、五种素材必须已在对应目录中。
3. 在客户端 `main_c/container.dat` 的 item.csv 加入/更新 ID 9999，名称、说明、图标、类型、功能和功能值与 item 一致；保留其他行和其他资源对象。
4. 后台 `item/9999.webp` 可复制 8887 图标；同步后台目录覆盖计数以及资源大小、CRC、SHA-256 和发布清单。客户端重新下载资源后识别新道具。
5. 使用此源码编译的配套服务端进行启动和开箱验证。尚未指定怪物/关卡，因此没有内置新增掉落来源。

不需要修改 APK。安卓实际显示仍需设备验收。运行包的详细备份与验证记录见 `E:/123/box-9999-notes/README.md`。
