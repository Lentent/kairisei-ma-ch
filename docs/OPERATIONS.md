# 本地运营台

服务运行后，在服务器本机访问 `http://127.0.0.1:26022/`（主端口 +2）。Windows 启动器也可打开 Admin；无桌面的服务器可通过 SSH 转发访问。后台不开放公网登录。

| 页面 | 操作 |
| --- | --- |
| 账号管理 | 查找 UID、账号绑定／解绑、重置密码、管理邮件；解绑不删除角色 |
| 礼物发放 | 选择玩家、奖励分类与职业筛选、批量发放；“全选本页”和“取消本页选择”只处理当前页，其他页保留 |
| 卡池 | 管理常规池的开放、价格、内容与概率；固定新手单抽／连抽不受运营池开关影响 |
| Boss 发布 | 活动／素材与往期 BOSS 分 Tab，分别保存开放名单和展示时间；普通及学习副本独立保留，尚非逐 Boss 排期或严格入场截止 |
| Boss 掉落 | 按往期／其他 BOSS／素材分类，再选难度、怪物／部位设置奖励；可复制同组难度；同副本 ID 在不同入口共用掉落配置 |
| 商店／兑换所 | 修改商品、货币价格、限购和上下架，批量添加素材；已用兑换次数保留 |
| 运营设置 | 水晶购买到账开关，默认关闭；关闭时购买正常返回但不增加购买水晶 |
| 公告与奖励 | 公告、签到奖励、新手毕业邮件、剧情首通奖励、看板价格与购买开关 |

点保存才会写入 SQLite 公共运营配置，重启保留；多人同时编辑发生版本冲突时应刷新后重新编辑。默认值来自随包配置，数据库中已保存的运营设置优先。此类改动不需要重新上传 CDN。

误发邮件可通过“账号管理 → 管理邮件”搜索，按未领取／已领取筛选，再单封或批量删除，每次最多100封。无需先领取即可删除；已领取的奖励不会回收，删除记录写入审计。同一批发放的请求重试不会恢复已删除邮件。

友情点池也在“卡池配置”中，可调整卡牌、权重、每抽价格、启停及排期；还需在“扭蛋发布”开放整组。连抽按余额决定抽数，每日首次免费规则保留。

玩家列表、赠礼目录、兑换商品和奖励弹窗均支持取消本页选择；原“清空选择”会取消全部页。掉落页切换筛选保留草稿，并显示正在编辑的副本。

普通签到每7次循环，新手签到发一轮，累计登录奖励独立计数。调整奖励不重置已领取记录，剧情首通奖励不补发给已通关账号；停售看板不回收已有看板，已开战的副本沿用原奖励计划。

新手毕业邮件默认关闭。可配置标题、正文，批量选择货币、卡牌、素材、道具、召唤石和传承卡，修改数量与卡牌等级／名声／忠诚度。完成全部九步新手训练后，按当时保存的配置发放一次，每种奖励一封邮件（最多120种）。注册、重登和初始战斗不会提前发送；已完成训练的账号不补发，重试不重复发放。背包满时可以稍后领取。

月卡与无穷卡目前是免费本地商品，不扣水晶。购买到账开关也控制购卡立即赠送的250／600水晶；关闭时仍开通卡权益。
月卡按北京时间计算30个领取日，续购累加天数；无穷卡永久有效。两张卡各自每天最多领取100水晶，购买次数不叠加每日收益，不重置当天领取记录，漏领不补。无穷卡重复购买不再发放600水晶。

当前关注和粉丝上限各50，系统伙伴也占关注名额；互关好友包含在关注列表内，所以等级公式虽可给出最高65个好友名额，实际互关人数仍受50关注名额限制。达到容量时返回正常提示。

备份时正常停止服务，保存完整 `_local/data/` 以及自己的 `cdn.json`、`cdn-sync.json` 和连接设置。不要把玩家数据或填写过密钥的配置放进源码仓库。

## 账号缓存容量

启动前设置环境变量 `KAIRI_ACCOUNT_CACHE_LIMIT` 可调整空闲账号处理器数量，默认32，范围0–4096（0禁用空闲缓存）。Windows启动器和Linux启动脚本均继承此变量；修改后重启服务端生效。PowerShell示例：`$env:KAIRI_ACCOUNT_CACHE_LIMIT='64'`，随后在同一终端启动服务；Linux示例：`KAIRI_ACCOUNT_CACHE_LIMIT=64 sh Start-Server-linux-amd64.sh 192.168.1.100`。

请求结束即进入空闲缓存，超过数量先淘汰最久未用项；5分钟未使用也会回收。请求执行中的账号不淘汰。增加容量以更多内存换取较少的重复加载；不是在线人数限制。

新手毕业邮件选择卡牌后，可用“全部满级／全部满名声”按各卡自身上限批量填写；检查后保存生效，不影响已有领取记录。
