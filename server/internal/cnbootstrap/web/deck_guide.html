四职业分工组卡与出牌评分与解锁

四个职业，配合出牌

佣兵 · 输出

围绕物理或魔法输出方向配置攻击与增益卡。根据敌人的属性、防御和部位选择目标，避免增益类型与攻击类型不匹配。

富豪 · 防护

根据敌方行动准备物理或魔法防御，留意抽卡效果。使用挑衅前确认自己能承受集中攻击，并与治疗配合。

盗贼 · 妨害

选择与敌人攻击类型相符的妨害，兼顾魔法输出。留意技能的目标、持续回合与触发条件，提前准备关键回合。

歌姬 · 治疗

根据队伍血量安排单体或全体治疗，在安全回合配合增益。持续恢复和即时治疗的生效时机不同，按技能说明安排。

组卡与出牌检查

  1. 先看副本。确认敌人属性、部位与主要攻击类型，再选择克制攻击、防御、妨害和恢复。
  2. 保留低费用选择。同一回合可以打出多张牌，总费用必须在当回合可用 COST 内；不要让关键回合只能等待。
  3. 核对觉醒和条件。卡牌是否适合当前职业、连锁数、目标及回合条件，都会影响实际效果。不要只看稀有度。
  4. 安排一整回合。围绕输出时机配合增益、妨害、治疗及同属性连锁；角色技能、骑士技能和其他已解锁能力也应按各自限制使用。
  5. 出发前复查。检查主卡、支援卡、职业与队长设置；评分较高并不代表能应对每一种敌人。

历史最高评价与解锁

达成过的最高卡组评价会保留。换成较低评价的卡组后，已获得的评分解锁不会收回。

卡组评价取属性评价与技能评价中较低的一项。提升卡牌等级、配置适合职业的卡牌有助于技能评价，但支援卡或单纯堆高某一项属性不能代替整组检查。
