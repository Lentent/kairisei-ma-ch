# 圣剑杯（世界 BOSS）后台数值编辑更新

基于 E:\MA 当前源码（HEAD 14145cf 加本次修改）构建。程序版本字符串沿用 1.3.9，后台网页已嵌入程序。

## 更新

1. 正常停止服务端。
2. 按服务器系统选择一个程序，替换服务端目录中的对应程序文件：Windows x64 使用 kairi-server.exe；Linux x64 使用 kairi-server-linux-amd64；Linux ARM64 使用 kairi-server-linux-arm64。
3. 保留现有部署配置、数据库和完整 resource-set，按原方式启动。Linux 的程序须具有可执行权限。
4. 刷新后台页面；如仍显示旧页面，强制刷新浏览器缓存。

本更新包不含玩家数据库、资源包或 APK，不会自动部署到正在运行的服务器。

## 使用

进入「战斗与活动 → 圣剑杯与探索」，选择圣剑杯，点击「修改 BOSS 数值」。也可从「Boss 发布 → 难度规则与属性 → 修改原版数值」进入。

切换到「使用自定义数值」，选择本体或部位，填写 HP、物攻、魔攻、防御、属性和抗性；原有招式伤害在另一页签调整。HP 支持 1 至 30 亿。留空沿用当前资源包原值，0 表示明确设为 0（HP 至少为 1）。最后点击「保存数值」。恢复原值也需要保存。

数值覆盖保存在数据库，重启后保留，用于新开的组队／AI 房间；已建立的房间保留开局快照，普通单人仍读取手机资源包原值。计分倍率、档位奖励、回合上限和起始 COST 继续在圣剑杯页面单独保存。修改数值保留奖励领取记录；圣剑杯仍不支持复制为自定义 BOSS。
