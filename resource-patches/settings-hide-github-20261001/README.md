# 设置页 GitHub 文字移除补丁

清空设置页原有 GitHub 地址文本。适用于本地已验证的 140.apk 配套资源，无需修改或重装 APK。

## 安装

1. 备份服务端现有 `resource-set`。
2. 解压 `settings-hide-github-20261001.zip`，将其中的 `resource-set` 目录按原路径合并覆盖到服务端运行目录。
3. 重启服务，让客户端重新检查并下载资源；如使用 CDN，同步更新对应资源后再检查。

本补丁只清空 `ui_option.dat` 中的一个文本控件，并同步 `version.dat`、`asset-map.json`、`resource-set.json` 的校验信息。其他 Unity 对象逐字节保持不变。

补丁包含制作时的完整资源索引。目标服务器如有后续或额外的自定义资源改动，须先合并索引，不能直接用旧索引覆盖。

这是一份资源增量包，不是完整资源集。拉取 Git 或重新编译服务端不会自动安装本补丁，仍需执行上述资源覆盖步骤。

资源重读、其他对象对比、CRC/SHA 和 ZIP 完整性检查通过；尚未进行手机或模拟器界面验证。详细校验见 `validation.json`。
